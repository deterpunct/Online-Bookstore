# 工具调用问题诊断指南

## 问题描述

**症状**：Cherry Studio中可以看到5个工具，但AI无法正确回答问题。

## 可能的原因

### 1. AI没有正确调用工具

**原因**：
- 工具描述不够清晰
- AI不理解何时应该调用工具
- 用户问题不够明确

**解决方案**：
- 使用更明确的提问方式
- 在问题中明确提到"搜索"、"查找"等关键词

**示例提问**：
```
❌ 不好的提问：三体
✅ 好的提问：帮我搜索"三体"这本书
✅ 更好的提问：使用search_books工具搜索"三体"
```

### 2. 工具调用参数错误

**原因**：
- AI传递的参数格式不正确
- 缺少必需参数
- 参数类型不匹配

**诊断方法**：
运行测试脚本：
```bash
node test-tools.js
```

这会测试工具调用是否正常工作。

### 3. 数据库查询失败

**原因**：
- 数据库连接失败
- 表不存在或没有数据
- SQL查询错误

**诊断方法**：
```bash
npm test
```

### 4. 返回数据格式问题

**原因**：
- 返回的JSON格式AI无法解析
- 数据太大导致截断
- 编码问题

## 诊断步骤

### 步骤1: 测试数据库连接

```bash
npm test
```

如果失败，检查：
- MySQL服务是否运行
- 数据库配置是否正确
- 表是否存在

### 步骤2: 测试工具调用

```bash
node test-tools.js
```

这会模拟Cherry Studio调用工具的过程，检查：
- 工具是否能被正确调用
- 参数是否正确传递
- 返回数据格式是否正确

### 步骤3: 在Cherry Studio中查看日志

1. 打开Cherry Studio日志文件
2. 搜索 "bookstore" 或工具名称
3. 查看是否有错误信息

### 步骤4: 尝试不同的提问方式

**方式1: 直接要求使用工具**
```
请使用search_books工具搜索"三体"
```

**方式2: 明确说明需求**
```
帮我查找书名包含"三体"的图书信息
```

**方式3: 使用自然语言但包含关键词**
```
搜索图书：三体
```

## 常见问题及解决方案

### 问题1: AI说"我无法访问数据库"

**可能原因**：
- AI没有识别到应该使用工具
- 工具调用失败但没有错误提示

**解决方案**：
1. 明确告诉AI使用工具：
   ```
   请使用search_books工具，参数：{"keyword": "三体"}
   ```

2. 检查工具是否真的可用：
   - 在Cherry Studio中查看工具列表
   - 确认工具描述清晰

### 问题2: AI调用了工具但返回空结果

**可能原因**：
- 数据库中没有匹配的数据
- 搜索关键词不匹配

**解决方案**：
1. 测试数据库是否有数据：
   ```bash
   npm test
   ```

2. 尝试更宽泛的搜索：
   ```
   搜索"Java"（而不是"Java编程思想"）
   ```

### 问题3: AI返回了JSON但格式混乱

**可能原因**：
- AI没有正确解析工具返回的JSON
- 返回数据太大

**解决方案**：
1. 检查工具返回的数据格式
2. 可能需要改进工具描述，让AI知道如何格式化输出

### 问题4: 工具调用超时

**可能原因**：
- 数据库查询太慢
- 网络问题
- 数据库连接池耗尽

**解决方案**：
1. 检查数据库性能
2. 优化SQL查询
3. 增加超时时间（如果Cherry Studio支持）

## 改进建议

### 1. 改进工具描述

当前工具描述已经比较清晰，但可以：
- 添加更多使用示例
- 说明返回数据的格式
- 明确参数要求

### 2. 添加更好的错误处理

在工具调用失败时，返回更友好的错误信息，帮助AI理解问题。

### 3. 添加日志记录

在MCP服务器中添加更详细的日志，方便调试。

## 测试工具调用

运行以下命令测试工具是否正常工作：

```bash
node test-tools.js
```

这会：
1. 启动MCP服务器
2. 初始化连接
3. 列出可用工具
4. 测试调用search_books工具
5. 显示返回结果

如果测试成功，说明工具本身工作正常，问题可能在于：
- AI没有正确调用工具
- 提问方式需要改进
- Cherry Studio的配置问题

## 下一步

1. **运行测试**：`node test-tools.js`
2. **检查结果**：查看工具调用是否成功
3. **改进提问**：使用更明确的提问方式
4. **查看日志**：检查Cherry Studio的错误日志

如果测试工具调用成功，但Cherry Studio中仍然无法使用，可能需要：
- 重启Cherry Studio
- 检查Cherry Studio的MCP配置
- 查看Cherry Studio的日志文件
