# MCP服务器使用前后对比说明

## 对比场景：查找图书信息

### 场景描述
用户在Cherry Studio中询问："帮我找一下三体这本书的信息"

---

## 一、不使用MCP服务器的情况

### 用户提问
```
用户：帮我找一下三体这本书的信息
```

### AI回答（不使用MCP）
```
抱歉，我无法直接访问您的数据库。要查找《三体》这本书的信息，您需要：

1. 打开浏览器访问您的在线书店系统（http://localhost:3000）
2. 在搜索框中输入"三体"
3. 查看搜索结果

或者，如果您能提供数据库的连接信息，我可以帮您编写SQL查询语句：

SELECT * FROM books WHERE title LIKE '%三体%';

您需要：
1. 连接到MySQL数据库
2. 执行上述SQL语句
3. 查看返回的结果

希望这能帮助到您！
```

### 特点分析
- ❌ **无法直接访问数据**：AI无法直接查询数据库
- ❌ **需要用户手动操作**：用户必须打开浏览器或执行SQL
- ❌ **回答不够直接**：只能提供建议，不能直接给出答案
- ❌ **用户体验差**：需要多步操作才能获取信息
- ❌ **信息不准确**：可能提供过时或不完整的信息

### 截图要点
1. 显示Cherry Studio界面
2. 用户提问框
3. AI回答区域，标注：
   - "无法直接访问数据库"
   - "需要手动操作"的提示
   - SQL查询语句（但无法执行）

## 二、使用MCP服务器的情况

### 用户提问
```
用户：帮我找一下三体这本书的信息
```

### AI回答（使用MCP）
```
让我为您查找《三体》这本书的信息。

[正在调用 search_books 工具...]

找到了《三体》这本书的详细信息：

📖 **书名**：三体
👤 **作者**：刘慈欣
📚 **ISBN**：9787536692930
💰 **价格**：¥68.00
📦 **库存**：55本
🏢 **出版社**：重庆出版社

**内容简介**：
中国科幻文学的代表作，讲述了地球文明与三体文明的星际冲突。本书获得了世界科幻文学最高奖项雨果奖。

需要我帮您查找其他图书吗？比如：
- 查找作者"刘慈欣"的其他作品
- 搜索价格在50-100元之间的图书
- 查找包含"科幻"关键词的图书
```

### 特点分析
- ✅ **直接访问数据库**：AI通过MCP服务器直接查询数据库
- ✅ **实时准确数据**：返回的是数据库中的最新数据
- ✅ **回答直接完整**：直接给出完整的图书信息
- ✅ **用户体验好**：一步到位，无需额外操作
- ✅ **功能扩展**：可以继续提供相关建议

### 截图要点
1. 显示Cherry Studio界面
2. 用户提问框
3. AI回答区域，显示：
   - 完整的图书信息（书名、作者、价格、库存等）
   - 格式化的数据展示
4. MCP工具调用日志（如果界面显示），标注：
   - `search_books` 工具被调用

   - 返回结果数量

## 四、更多对比示例

### 示例1：按作者查找

**不使用MCP**：
```
用户：查找作者"刘慈欣"的所有图书

AI：我无法直接查询数据库。您可以：
1. 在网站搜索框中输入"刘慈欣"
2. 或者执行SQL：SELECT * FROM books WHERE author LIKE '%刘慈欣%';
```

**使用MCP**：
```
用户：查找作者"刘慈欣"的所有图书

AI：[调用 get_books_by_author 工具]

找到了刘慈欣的 1 本图书：
- 三体 (¥68.00, 库存55本)
```

### 示例2：价格范围查询

**不使用MCP**：
```
用户：查找价格在50到100元之间的图书

AI：您需要执行以下SQL查询：
SELECT * FROM books WHERE price >= 50 AND price <= 100;
```

**使用MCP**：
```
用户：查找价格在50到100元之间的图书

AI：[调用 get_books_by_price_range 工具]

找到了 8 本价格在50-100元之间的图书：
1. 活着 - 余华 (¥35.00)
2. 边城 - 沈从文 (¥25.00)
...
```
