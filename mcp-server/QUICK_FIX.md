# 快速修复：工具可见但无法使用

## 问题
Cherry Studio中可以看到5个工具，但AI无法正确回答问题。

## 快速解决步骤

### 步骤1: 重启Cherry Studio（最重要！）

**原因**：工具描述已更新，需要重启才能生效。

1. **完全关闭**Cherry Studio（不是最小化）
2. **重新启动**Cherry Studio
3. 等待MCP服务器重新连接

### 步骤2: 测试工具调用

运行测试脚本检查工具是否正常工作：

```bash
npm run test-tools
```

如果测试成功，说明工具本身没问题。

### 步骤3: 使用正确的提问方式

**改进后的工具描述**现在更清晰，但您也可以尝试这些提问方式：

#### ✅ 推荐的提问方式：

1. **直接搜索**：
   ```
   搜索"三体"这本书
   ```

2. **明确说明**：
   ```
   帮我找一下三体这本书的信息
   ```

3. **使用关键词**：
   ```
   查找包含"Java"的图书
   ```

4. **按作者查找**：
   ```
   查找作者"刘慈欣"的所有图书
   ```

#### ❌ 避免的提问方式：

- 只说"三体"（太简短）
- "数据库里有三体吗"（AI可能不会调用工具）
- "告诉我三体的信息"（不够明确）

### 步骤4: 如果仍然不行

#### 检查1: 查看Cherry Studio日志

找到日志文件（参考CHECK_CONNECTION.md），搜索：
- `bookstore`
- `search_books`
- `error`

查看是否有错误信息。

#### 检查2: 手动测试工具

在Cherry Studio中，尝试明确告诉AI使用工具：

```
请使用search_books工具，参数：{"keyword": "三体"}
```

如果这样能工作，说明工具正常，只是AI没有自动识别何时使用。

#### 检查3: 验证数据库连接

```bash
npm test
```

确保数据库连接正常且有数据。

## 常见问题

### Q: 重启后还是不行？

A: 检查：
1. Cherry Studio是否真的完全关闭了（检查任务管理器/活动监视器）
2. MCP服务器是否重新连接（查看状态指示器）
3. 运行 `npm run test-tools` 查看工具是否正常

### Q: 测试工具调用成功，但Cherry Studio中还是不行？

A: 可能是AI没有识别到应该使用工具。尝试：
1. 更明确的提问："使用search_books工具搜索三体"
2. 检查Cherry Studio的AI模型设置
3. 查看Cherry Studio的日志文件

### Q: 如何确认工具描述已更新？

A: 在Cherry Studio中查看工具列表，`search_books`的描述应该包含"Use this tool when the user asks to find, search..."等英文说明。
